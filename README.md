# Particle Forge

A polished HTML canvas sandbox inspired by particle-based simulation games. This project is built with plain HTML, CSS, and JavaScript so you can run it locally without any build tools.

## Run it locally

1. Open the project folder in your browser.
2. Double-click `index.html` or serve it with a local web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Features

- Particle-based sandbox simulation with sand, water, fire, smoke, lava, oil, plant, acid, ice, metal, and more
- Material picker panel with many interactive elements
- Paint, erase, and heat tools
- Adjustable brush size
- Random terrain generation
- Screenshot export
- Responsive UI with a polished dark aesthetic

## Controls

- Left click: paint with the selected material
- Right click: erase
- Scroll wheel: change brush size
- Q / E: cycle materials
- Pause button: freeze simulation
- Screenshot button: save the current canvas as an image

## Files

- `index.html` – app layout
- `style.css` – game UI styling
- `script.js` – simulation logic and interactions

## Notes

This is a lightweight HTML version inspired by large sandbox simulation games, designed to be visually rich and browser friendly while staying easy to edit.
